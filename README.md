# Vibe Coders Croatia

Hrvatska otvorena zajednica dizajnera, programera i product buildera.

**Website:** [vibecoders.hr](https://vibecoders.hr)

## Tech Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
pnpm preview
```
