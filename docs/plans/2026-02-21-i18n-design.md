# i18n Design: Multi-Language Support (HR + EN)

## Overview

Add English language support to the Vibe Coders Croatia website. Croatian remains the default language. Users can switch to English via a language toggle.

## Decisions

- **Framework:** react-i18next (i18next + react-i18next)
- **Languages:** Croatian (hr) — default, English (en)
- **Routing:** URL-based. `/` serves Croatian, `/en/` serves English
- **Persistence:** URL is the source of truth (shareable, SEO-friendly)
- **Future languages:** Not planned — optimized for exactly two languages

## Architecture

### URL Structure

| URL | Language |
|-----|----------|
| `/` | Croatian (default, no prefix) |
| `/en/` | English |
| `/*` | 404 |

### React Router

Routes serve the same `<Index />` page. A `LanguageSync` component reads the URL path and calls `i18n.changeLanguage()`. Invalid language codes fall through to 404.

```
<BrowserRouter>
  <Routes>
    <Route path="/" element={<Index />} />
    <Route path="/en/" element={<Index />} />
    <Route path="*" element={<NotFound />} />
  </Routes>
</BrowserRouter>
```

### i18next Configuration

- Single `translation` namespace
- Both languages loaded eagerly (payload is small)
- Custom language detector reads from URL path
- Fallback language: `hr`
- Dynamically sets `<html lang="">` attribute

### File Structure

```
src/
  i18n/
    index.ts          # i18next init config
    locales/
      hr.json         # Croatian translations
      en.json         # English translations
```

## Language Picker

### Placement

Fixed top-right corner of the viewport. Always visible regardless of scroll position.

### Visual Design

- Monospace font (`font-mono`), 11px, uppercase, wide tracking
- Matches the editorial/developer aesthetic of the site
- Active language: `text-foreground`
- Inactive language: `text-muted-foreground/40`
- Separated by a `·` dot
- Hover on inactive: `text-sunset-orange`
- No background or border — floating text
- Position: `fixed top-6 right-6 z-50`
- Mobile: `top-4 right-4` with larger touch target

### Behavior

- Clicking the inactive language navigates to the corresponding URL
- HR click → navigates to `/`
- EN click → navigates to `/en/`
- Preserves hash anchors (#about, #projects, #sponsors)

## Components to Modify

1. **HeroSection.tsx** — 4 taglines
2. **AboutSection.tsx** — Section labels, heading, description, 4 activity cards, eligibility text
3. **ProjectsSection.tsx** — Section labels, heading, description, empty state, fallback
4. **SponsorsSection.tsx** — Section labels, heading, description
5. **Footer.tsx** — Nav links, description, GDPR text, footer note
6. **NotFound.tsx** — 404 message, back link
7. **App.tsx** — Route setup, i18n provider
8. **index.html** — hreflang tags, dynamic lang attribute

## Not Translated

- "VIBE CODERS CROATIA" (brand name)
- "est. 2026 · Zagreb, HR" (provenance label)
- Tech names in the ticker (React, TypeScript, etc.)
- Social platform names (Discord, Meetup, GitHub)

## SEO

- `<html lang="">` dynamically set to `hr` or `en`
- `<link rel="alternate" hreflang="hr" href="https://vibecoders.hr/" />`
- `<link rel="alternate" hreflang="en" href="https://vibecoders.hr/en/" />`
- Meta description updated per language
- Open Graph and Twitter Card tags updated per language
- Structured data description updated per language

## Dependencies

- `i18next` — core i18n framework
- `react-i18next` — React bindings for i18next
